# Results section

`results_section.tex` is the separate LaTeX results section requested in the
September instructions: per season SURD analysis of the five historical NGC 5548
campaigns (see [EPOCH_ANALYSIS.md](../EPOCH_ANALYSIS.md)). It has eight tables,
seven pages of text and 120 component figures (one per epoch, variable set,
target and lag configuration). Each figure shows the 26 normalized components
(U, R and S panels) and the normalized leakage against lag, as in thesis
Figures 4.1 to 4.3 with lag on the horizontal axis.

## Files

| File | Content |
| :--- | :--- |
| `results_section.tex` | The section; include in a manuscript |
| `preview.tex`, `references.tex` | Minimal wrapper and the six references |
| `epoch_*_rows.tex` | Tables generated by `python -m collaborator_rebuild.summarize_epoch` |
| `epoch_figures.tex` | Figure list that includes the pages of the atlas PDFs |
| `calibration_rows.tex` | Independent categorical benchmark table |
| `previous_native_date_analysis.tex` and its `*_rows.tex`, `figures/` | The 7 October native date analysis, kept for history |

The compiled review copy is `output/pdf/surd_epoch_results.pdf` (131 pages).
Figure pages come from `collaborator_rebuild/epoch_results/figures/atlas_*.pdf`.

## Reproduce

```sh
python -m collaborator_rebuild.epoch_scan
python -m collaborator_rebuild.summarize_epoch
mkdir -p tmp/pdfs/surd_section_build output/pdf
tectonic --keep-logs --outdir tmp/pdfs/surd_section_build collaborator_rebuild/results_section/preview.tex
cp tmp/pdfs/surd_section_build/preview.pdf output/pdf/surd_epoch_results.pdf
```

## Manuscript integration

The host document needs `graphicx`, `amsmath`, `booktabs`, `float` and `natbib`.
Set `\SURDResultsPath` to this folder and `\SURDEpochPath` to
`collaborator_rebuild/epoch_results` relative to the compiling document (the
defaults assume the repository root). Add the six `CR` citation keys to the host
bibliography; `references.tex` records their metadata. The preview disables
hyphenation with `\hyphenpenalty=10000` and `\exhyphenpenalty=10000`.

The astrophysical wording still needs the reading of Xi et al. 2025 and Lu et al.
2022 by the author responsible for it.
